# Aurahost — واجهة عرض عامة

موقع ثابت باللغة العربية لمعاينة شكل لوحة Aurahost. هذه النسخة **واجهة تجريبية فقط** ولا تتضمن تسجيل دخول أو رفع ملفات أو تشغيل مشاريع وأوامر أو تخزين بيانات مستخدمين.

## الملفات
- `index.html` — الصفحة الرئيسية.
- `styles.css` — التنسيق المتجاوب.
- `app.js` — تفاعل توضيحي محلي فقط.
- `.github/workflows/pages.yml` — سير عمل النشر إلى GitHub Pages.

## النشر على GitHub Pages
افتح **Settings → Pages** واختر **GitHub Actions** كمصدر النشر. سير العمل يبدأ تلقائيًا بعد دفع الملفات إلى `main`. رابط الموقع المتوقع: https://sahnk3511-max.github.io/aurahost-public/ .

## تحذير
لا تضع أسرار OAuth أو كلمات مرور أو مفاتيح API في ملفات الواجهة أو Git. تشغيل ملفات يرفعها المستخدمون يحتاج إلى خدمة خلفية منفصلة وعزل أمني وحدود موارد ومراجعة مستقلة؛ هذا المشروع لا يشغّل ملفات الزوار.
